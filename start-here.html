The art director pass

  

    
Claude can’t see its own page the way you do. This prompt makes it look again with a critical eye and fix what reads as generic. Do it once, after the bold move.

    
Look at this page as a demanding art director. List the five things that look most generic, clumsy or invented, then fix all five without changing the content. Then go through the craft rules in the style guide one by one and fix anything that breaks them. Give me the whole page again.

Rescue prompts.

    
Copy the one that matches and paste it into the same chat, in Chat or in Code. Still stuck after two tries? Raise a hand.

Test in Code · 6 minutes

    
Let Claude Code check it and get it ready.

    
Claude Code reads the kit’s CLAUDE.md, so it already knows what to check: errors, phone width, text size, contrast, motion, reduced motion, forms and readability. It fixes what fails without changing your design.

  

    

      
1. Open the kit in the Code tab

      
    
        
  1. In Claude Desktop, click the Code tab, then New.
    2. 
        
  2. Under the prompt box, set the environment to Local.
    3. 
        
  3. Use the project folder control to pick design-gathering-workshop-main.
    4. 
      

    

    

      
2. Paste this, then your page code

      
Here is my page from Claude Chat. Save it as site/index.html, run every check in CLAUDE.md at phone and desktop width, fix only what fails without changing the design, show it to me in the Browser pane, and report with the table.

      

      
Done when every row in Claude Code’s table says Pass or Fixed.

Put it live · 5 minutes

    
Drag a folder. Get a link.

    
Netlify Drop publishes a folder as a website. Sign in to Netlify first, so the site stays in your account.

  
    
    
  1. Sign in
    Sign in at netlify.com, so the site stays in your account.
    2. 
    
  2. Open Drop
    Open app.netlify.com/drop.
    3. 
    
  3. Drag the folder
    Drag the kit’s site folder onto the page. The folder, not the file inside it.
    4. 
    
  4. Share it
    Open the link on your phone. Then post it where the gallery is collected.
    5. 
  

  
Change something later? Change it in Chat, test it in Code again, then drag the site folder onto your site’s Deploys page in Netlify. The link stays the same.
